Namelist Admin

Open your data folder

Pick the shared folder that contains (or will contain) namelist.xlsx. Your browser will ask you to allow this page to edit files in that folder — choose Allow.

You will be asked once per session. Every Save writes three things: the Excel master file, the data.js snapshot the teacher page reads, and a timestamped backup in backups/. Use the app's own folder here — not the folder holding the school's official files; those are only ever opened read-only, via the School files tab.

This browser does not support folder access. Please open this page in Google Chrome or Microsoft Edge.

Press Enter or click anywhere to reconnect. Browsers will not keep a folder permission for a page opened from a drive, so this one click is unavoidable — it is the only one.

    Update levels from the school's files

    Connect the folder, then pick which file is each level's namelist — the files can be named anything. Your choice is stored in namelist.xlsx, so every admin on every device sees the same assignment (only the folder itself is connected per device, so drive letters and UNC paths don't matter). Updates match students by name, so their groups are kept, and only that level's classes are touched. The school's files are opened strictly read-only — the folder permission this page requests is read-only, so the browser itself blocks any change to them. Nothing in this app can ever modify the official files.
