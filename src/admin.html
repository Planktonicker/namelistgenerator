Open your data folder

Pick the shared folder that contains (or will contain) namelist.xlsx. Your browser will ask you to allow this page to edit files in that folder — choose Allow.

You will be asked once per session. Every Save writes three things: the Excel master file, the data.js snapshot the teacher page reads, and a timestamped backup in backups/. Use the app's own folder here — not the folder holding the school's official files; those are only ever opened read-only, via the School files tab.

This browser does not support folder access. Please open this page in Google Chrome or Microsoft Edge.

    Update levels from the school's files

    Register each level with a filename pattern (e.g. “Sec 1 Subject Allocation”). When the school saves a new version — even under a new dated name — choose the folder and the newest matching file is found automatically. Updates match students by name, so their groups are kept, and only that level's classes are touched. The school's files are opened strictly read-only — the folder permission this page requests is read-only, so the browser itself blocks any change to them. Nothing in this app can ever modify the official files.
